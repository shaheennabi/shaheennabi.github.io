Overview

This project brings the post-training workflow into an extensible system: generating and executing agent rollouts, verifying outcomes, updating models, and evaluating capability improvements. The emphasis is on reproducible experiments and infrastructure that supports increasingly long and complex tasks.

The repository already contains model and evaluation components, reasoning experiments, and early RL training work. Long-horizon agent training and distributed RL infrastructure are active development directions.

System components

Task & environment→Rollout generation→Verification→RL training→Evaluation

Agent environments

Long-horizon coding and tool-use tasks with controlled execution, state, and interaction traces.

Rollout & orchestration

Generate, schedule, collect, and manage trajectories for distributed RL experiments.

Verifiers & evaluation

Check task outcomes, localize failures, and measure progress across multi-step trajectories.

Training & inference

Connect policy updates, model execution, and evaluation in a reusable post-training pipeline.

Current research directions

  • Training open-weight models on long-horizon coding and agentic tasks.
  • Building reliable rollout, environment, verifier, and evaluation infrastructure.
  • Scaling distributed RL workloads and improving end-to-end training throughput.
  • Studying failures in context retention, planning, state tracking, and execution.
