Overview

An open effort to understand, implement, benchmark, and optimize the systems behind large-scale model training.

The project connects distributed computing fundamentals with accelerator programming and end-to-end performance engineering. Current development focuses on JAX sharding, device meshes, collective communication, and performance modeling, with the longer-term goal of a distributed transformer training stack. It is also the performance layer for the open post-training system.
