Upload instructions:
1. Copy everything in this folder over your repository root (index.html, assets/, open-posttraining/, open-distributed-system/).
   Your existing files (resume PDFs, photos, google235ee6caeeb5a685.html) are included unchanged. Keep google235ee6caeeb5a685.html at the root.
2. Commit and push to main.

Preview locally: open index.html directly in a browser. All paths are relative, so it works from a folder or from GitHub Pages.
Fonts (Google Fonts) and the YouTube player need an internet connection.

Filling in the project pages: search each page for "EDIT". Every placeholder (todo notes, table rows, figure boxes, glance values, stage panels) has one.
To add a figure: put the image next to the page and replace the text inside <div class="box"> with <img src="..." alt="...">.
