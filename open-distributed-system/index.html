Overview

An open-source effort to understand, implement, benchmark, and optimize the systems behind large-scale model training. The project connects distributed computing fundamentals with practical accelerator programming and end-to-end performance engineering.

Current development focuses on JAX sharding, device meshes, collective communication, and performance modeling, with the longer-term goal of building a distributed transformer training stack.

System areas

Model workload→Sharding & parallelism→Collectives→Accelerator kernels→Profiling

Distributed execution

Device meshes, sharding, data and tensor parallelism, and multi-device execution.

Communication

Collective operations, communication patterns, synchronization, and data movement.

Accelerator kernels

GPU and TPU programming, tiled computation, memory hierarchies, and kernel optimization.

Performance engineering

Roofline analysis, profiling, benchmarking, bottleneck analysis, and throughput optimization.

Long-term direction

  • Build a distributed transformer training implementation from first principles.
  • Optimize compute, memory movement, and collective communication across accelerators.
  • Develop reusable performance benchmarks and profiling workflows.
  • Connect distributed training infrastructure with the open post-training and RL stack.
